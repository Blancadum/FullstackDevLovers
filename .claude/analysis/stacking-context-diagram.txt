Z-INDEX VALUE RANGES
====================

Reserved Ranges (DO NOT USE)

 0 -  50:  Base content layer
50 - 100:  Component dropdowns, popovers
100- 500:  Navigation, sidebars
500- 999:  Modals, overlays
1000+:    System-level (notifications, alerts)

Current Conflicts:
├─ 1000: SearchResults + ScrollToTop (both)
├─ 500: LessonSidebar + Overlay
└─ 100: Navbar + Header + TableOfContents


PERFORMANCE COMPARISON
======================

ABSOLUTE POSITIONING
─────────────────────
Layout:    Hero → ClusterSearch → SearchResults
Position:  Relative to .search-container
Reflow:    YES (on scroll, parent resize)
Paint:     YES (when ancestor repaints)
Mobile:    SLOW (15-20% impact)
Overflow:  Can be clipped by parent

    Browser
       ↓
    Layout Engine
       ↓ (searches ancestors for positioning context)
    ClusterSearch (relative)
       ↓
    SearchResults (absolute) ← Needs reflow on any ancestor change


FIXED POSITIONING (PORTAL)
──────────────────────────
Layout:    DocumentRoot → DropdownRoot
Position:  Fixed to viewport
Reflow:    NO
Paint:     Only on explicit changes
Mobile:    FAST (2-3% impact)
Overflow:  Never clipped

    Browser
       ↓
    Layout Engine
       ↓ (searches for fixed positioning root)
    DocumentRoot
       ↓
    SearchResults (fixed) ← No ancestor affect


STACKING CONTEXT CREATION METHODS
==================================

Current: NO explicit stacking context
    .cluster-search {
        padding: 0;
        background: transparent;
        /* NO: position, z-index, transform, etc. */
    }

Option A: Explicit z-index
    .cluster-search {
        position: relative;
        z-index: 50;  /* Creates stacking context */
    }

Option B: Isolation (CSS Containment)
    .cluster-search {
        isolation: isolate;  /* Creates stacking context without z-index */
    }

Option C: Other (transform, filter, etc.)
    .cluster-search {
        transform: translateZ(0);  /* Creates stacking context */
    }

BEST: Portal (removes need for z-index entirely)
    No stacking context needed when in document root!
